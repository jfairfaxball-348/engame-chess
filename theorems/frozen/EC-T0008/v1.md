# EC-T0008 v1 — Finite-rank clock-free forced-mate reasoning

**Status:** FROZEN (S025, 2026-10-19). Source candidate: EC-C009.
**Representative ledger declaration:** `EndgameChess.Rules.forceMate_defend`.
**Attribution:** classical finite reachability-game reasoning; no novelty claim.

## Statement and exact scope

This theorem bundle supplies sound reasoning rules for the project's explicitly defined **clock-free, repetition-free, finite-rank forced-mate game** over the FIDE 2023 legal-move kernel. It applies to arbitrary kernel positions and either named winning colour. It does not assume the position has globally arisen.

For colour σ, `MateGoal σ q` means q.turn is σ's opponent and that player is kernel-checkmated. `MateWithin σ n q` uses at most n plies: a goal already reached wins immediately; otherwise q must not be dead, the named winner chooses a legal successor, and the defender must have a nonempty legal reply set all of whose successors win within the remaining budget. `ForceMate σ q := ∃ n, MateWithin σ n q`.

The frozen mathematical declarations establish:

1. Monotonicity in the ply budget (`mateWithin_mono_step`, `mateWithin_mono`).
2. Every forcing certificate contains a kernel-legal path to the correct checkmate (`mateWithin_sound`); consequently forcing implies not dead (`forceMate_not_dead`). This implication does not identify cooperative liveness with forcing.
3. A goal is a zero-ply forcing win (`forceMate_of_goal`). At a no-move position, forcing holds iff the opponent is already checkmated (`forceMate_no_moves_iff`); stalemate is not a forcing win (`stalemate_not_forceMate`).
4. One legal defender reply to a dead successor refutes forcing (`dead_reply_not_forceMate`).
5. A chosen legal forcing successor wins on the named winner's turn (`forceMate_choose`). On the defender's turn, a **nonempty** set of legal replies, each forcing with some finite bound, has a common finite bound and gives forcing at the current node (`forceMate_defend`). The proof combines bounds over the finite move-generator list using its proved correspondence with kernel `Legal`.

The game predicate is a definition, not an independently derived complete FIDE outcome model. No equivalence with a separately represented arbitrary eventual-winning strategy is claimed. These are semantic/closure theorems, not a KRK forced-win classification or a class-wide enumeration.

## Frozen statements — verbatim exact-source `#check` output

```text
@EndgameChess.Rules.mateWithin_mono_step : ∀ {σ : EndgameChess.KK.Colour} {n : Nat} {q : EndgameChess.Rules.Position},
  EndgameChess.Rules.MateWithin σ n q → EndgameChess.Rules.MateWithin σ (n + 1) q
@EndgameChess.Rules.mateWithin_mono : ∀ {σ : EndgameChess.KK.Colour} {n m : Nat} {q : EndgameChess.Rules.Position},
  EndgameChess.Rules.MateWithin σ n q → n ≤ m → EndgameChess.Rules.MateWithin σ m q
@EndgameChess.Rules.mateWithin_sound : ∀ {σ : EndgameChess.KK.Colour} {n : Nat} {q : EndgameChess.Rules.Position},
  EndgameChess.Rules.MateWithin σ n q → ∃ t, EndgameChess.Rules.ReachK q t ∧ EndgameChess.Rules.MateGoal σ t
@EndgameChess.Rules.forceMate_not_dead : ∀ {σ : EndgameChess.KK.Colour} {q : EndgameChess.Rules.Position},
  EndgameChess.Rules.ForceMate σ q → ¬EndgameChess.Rules.DeadK q
@EndgameChess.Rules.forceMate_of_goal : ∀ {σ : EndgameChess.KK.Colour} {q : EndgameChess.Rules.Position},
  EndgameChess.Rules.MateGoal σ q → EndgameChess.Rules.ForceMate σ q
@EndgameChess.Rules.forceMate_no_moves_iff : ∀ {σ : EndgameChess.KK.Colour} {q : EndgameChess.Rules.Position},
  (¬∃ r, EndgameChess.Rules.Legal q r) → (EndgameChess.Rules.ForceMate σ q ↔ EndgameChess.Rules.MateGoal σ q)
@EndgameChess.Rules.dead_reply_not_forceMate : ∀ {σ : EndgameChess.KK.Colour} {q r : EndgameChess.Rules.Position},
  q.turn = σ.opp → EndgameChess.Rules.Legal q r → EndgameChess.Rules.DeadK r → ¬EndgameChess.Rules.ForceMate σ q
@EndgameChess.Rules.stalemate_not_forceMate : ∀ {σ : EndgameChess.KK.Colour} {q : EndgameChess.Rules.Position},
  EndgameChess.Rules.inCheck q q.turn = false → (¬∃ r, EndgameChess.Rules.Legal q r) → ¬EndgameChess.Rules.ForceMate σ q
@EndgameChess.Rules.forceMate_choose : ∀ {σ : EndgameChess.KK.Colour} {q r : EndgameChess.Rules.Position},
  q.turn = σ → EndgameChess.Rules.Legal q r → EndgameChess.Rules.ForceMate σ r → EndgameChess.Rules.ForceMate σ q
@EndgameChess.Rules.forceMate_defend : ∀ {σ : EndgameChess.KK.Colour} {q : EndgameChess.Rules.Position},
  q.turn = σ.opp →
    (∃ r, EndgameChess.Rules.Legal q r) →
      (∀ (r : EndgameChess.Rules.Position), EndgameChess.Rules.Legal q r → EndgameChess.Rules.ForceMate σ r) →
        EndgameChess.Rules.ForceMate σ q
```
