# EC-T0005 v1 — King and knight versus king is dead in the general FIDE rules kernel (either orientation; any legal arrival; arisen positions)

**Status:** FROZEN (session S013, 2026-10-18). Source candidate: **EC-C003**.
**Proof-source commit:** `3adcebbb4ae643a62c8bf18b478bf70da774dbf8` (S012). This manifest is in a later commit and does not cite its own SHA.
**Attribution:** classical. K+N vs K is a standard example of insufficient mating material. Nothing here is claimed as novel. The contribution is a quantifier-correct, machine-checked derivation from the single auditable encoding of the FIDE 2023 Laws.

## Statement
**Scope.** Orthodox chess on the 8×8 board under the general rules kernel `formal/EndgameChess/Rules/`, a Lean encoding of the FIDE Laws of Chess effective 1 January 2023 (https://handbook.fide.com/chapter/E012023), Articles 1.2, 1.4.1, 2.1–3.10 and 5.2.2. The material is exactly king + knight against a lone king, either colour as the strong side.

**Theorem (prose).** Let `q` be a kernel position holding exactly a king and a knight of colour `σ` and a lone king of the other colour (either orientation), with any side to move and any castling/en-passant flags. If `q` was produced by a legal move from **any** position (any material, e.g. a capture of the last other piece), then `q` is dead: no series of legal moves from `q` reaches a checkmate. In particular every arisen K+N vs K position is dead, and under `Rule5_2_2` it is drawn immediately.

This is a **no-possible-mate** statement, stronger than "no forced mate". It is distinct from the stalemate, repetition, 50-move and 75-move rules (stalemates occur in this material and are irrelevant: the game has already ended by 5.2.2).

**Definition (Lean source, `Rules/KNK.lean`):**
```lean
def knkBoard (σ : Colour) (sk ns wk : Square) : Board := fun s =>
  if s = sk then some ⟨σ, .king⟩
  else if s = ns then some ⟨σ, .knight⟩
  else if s = wk then some ⟨σ.opp, .king⟩
  else none

def IsKNK (q : Position) (σ : Colour) (sk ns wk : Square) : Prop :=
  sk ≠ ns ∧ sk ≠ wk ∧ ns ≠ wk ∧ q.board = knkBoard σ sk ns wk
```

**Rule corollary (Lean, verbatim).** `Rule5_2_2` is a **named normative encoding of Art. 5.2.2, not a theorem**:
```
def EndgameChess.Rules.Rule5_2_2 : EndgameChess.Rules.Position → EndgameChess.Rules.GameResult → Prop :=
fun q r => EndgameChess.Rules.Arisen q ∧ EndgameChess.Rules.DeadK q ∧ r = EndgameChess.Rules.GameResult.draw
@EndgameChess.Rules.knk_drawn_by_rule : ∀ {q : EndgameChess.Rules.Position} {σ : EndgameChess.KK.Colour}
  {sk ns wk : EndgameChess.KK.Square},
  EndgameChess.Rules.Arisen q →
    EndgameChess.Rules.IsKNK q σ sk ns wk → EndgameChess.Rules.Rule5_2_2 q EndgameChess.Rules.GameResult.draw
```
