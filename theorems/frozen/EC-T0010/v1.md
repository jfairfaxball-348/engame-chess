# EC-T0010 v1 — Distant-or-protected rook safety for every legal reply

**Status:** FROZEN (S027, 2026-10-19). Source candidate: EC-C012.
**Representative:** `EndgameChess.Rules.krk_safe_reply`.

## Exact statement and scope

Let q contain exactly the strong king S and rook R of colour σ and the other colour's lone king W on distinct squares (`IsKRK q σ S R W`), with `q.turn = σ.opp`. Both colours, arbitrary castling/en-passant flags, and initial check are allowed; no global-reachability or last-arrival assumption is imposed.

`SafeRook S R W := 2 ≤ dInf R W ∨ dInf S R = 1`, where `dInf` is Chebyshev distance on the 8×8 board. For **every** kernel-legal successor r, `krk_safe_reply` supplies a square T with `Matches r σ ⟨S,R,T,true⟩` and a `StepM.lone` non-capturing king step. The rook survives, the kings remain at least distance two apart, and no rook ray checks the resulting lone king. `Matches` means exact KRK board and the indicated side to move; `StepM` here requires a unit king step, no rook capture, king separation and no rook ray.

`krk_safe_rank_reply` additionally assumes `S.rank < R.rank < W.rank` and proves `R.rank < T.rank` for every legal reply. `DistantBarrier S R W := S.rank < R.rank ∧ R.rank < W.rank ∧ 2 ≤ dInf R W` is the companion definition frozen with this module and used by EC-T0011. `krk_safe_weak_live` requires an **actual nonempty legal reply set** in addition to safety, and concludes `¬ DeadK q` via EC-T0007 and a prefixed mating path.

This is sufficiency for immediate safety and a rank barrier; it does not assert any reply exists, preserve safety indefinitely, characterise all available captures, or prove forcing. A protected rook is not required in the distant disjunct. The proof starts from arbitrary kernel `Legal`, excludes capture by distance or post-move self-check, then extracts `StepM`; it does not assume cooperative model soundness is completeness.

## Complete frozen theorem bundle — verbatim exact-source #check output

```text
@EndgameChess.Rules.krk_safe_reply : ∀ {q r : EndgameChess.Rules.Position} {σ : EndgameChess.KK.Colour}
  {sk rs wk : EndgameChess.KK.Square},
  EndgameChess.Rules.IsKRK q σ sk rs wk →
    q.turn = σ.opp →
      EndgameChess.Rules.SafeRook sk rs wk →
        EndgameChess.Rules.Legal q r →
          ∃ t,
            EndgameChess.Rules.Matches r σ { sk := sk, rs := rs, wk := t, strong := true } ∧
              EndgameChess.Rules.StepM { sk := sk, rs := rs, wk := wk, strong := false }
                { sk := sk, rs := rs, wk := t, strong := true }
@EndgameChess.Rules.krk_safe_rank_reply : ∀ {q r : EndgameChess.Rules.Position} {σ : EndgameChess.KK.Colour}
  {sk rs wk : EndgameChess.KK.Square},
  EndgameChess.Rules.IsKRK q σ sk rs wk →
    q.turn = σ.opp →
      EndgameChess.Rules.SafeRook sk rs wk →
        ↑sk.snd < ↑rs.snd →
          ↑rs.snd < ↑wk.snd →
            EndgameChess.Rules.Legal q r →
              ∃ t,
                EndgameChess.Rules.Matches r σ { sk := sk, rs := rs, wk := t, strong := true } ∧
                  EndgameChess.Rules.StepM { sk := sk, rs := rs, wk := wk, strong := false }
                      { sk := sk, rs := rs, wk := t, strong := true } ∧
                    ↑rs.snd < ↑t.snd
@EndgameChess.Rules.krk_safe_weak_live : ∀ {q : EndgameChess.Rules.Position} {σ : EndgameChess.KK.Colour}
  {sk rs wk : EndgameChess.KK.Square},
  EndgameChess.Rules.IsKRK q σ sk rs wk →
    q.turn = σ.opp →
      EndgameChess.Rules.SafeRook sk rs wk → (∃ r, EndgameChess.Rules.Legal q r) → ¬EndgameChess.Rules.DeadK q
```
