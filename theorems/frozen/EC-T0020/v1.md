## Exact statement and semantic scope

For every universe-polymorphic state type X, Layer L, named colour σ, budget n
and state s, RuleMateWithin L σ n s implies frozen MateWithin σ n (L.erase s).
The IDENTICAL board-ply budget is preserved. RuleForceMate L σ s consequently
implies frozen ForceMate σ (L.erase s), using the same uniform witness n.

Layer data are erase, BoardStep, Ongoing, CanClaim, independent of σ and n.
At EVERY ongoing state, ordinary proof fields require: (A) every BoardStep
projects to kernel Legal; (B) EVERY raw Legal successor lifts to a BoardStep
with that exact erased target; (C) ongoing implies not DeadK at erasure.
The interface never assumes a winning continuation. These fields are quantified
proof hypotheses, not additional global Lean axioms.

Goal is EXACTLY the frozen named MateGoal. The finite recurrence permits a
terminal goal, otherwise ongoing winner existential moves or nonempty universal
defender replies with no available defender claim. Claims are draws, not
BoardStep actions consuming hidden plies. Draw-ending children cannot be
pruned from the reply relation. The proof generalises s and inducts on n;
it projects an arbitrary raw Legal defending reply by field B. It does not
weaken all-defences forcing to cooperative reachability or choose bounds after
a reply. Exact authoritative statements and interface fields are reproduced
below, together with the unchanged source recurrence.

This is a conditional ABSTRACT interface theorem over the FIDE 2023 legal-move
kernel and EC-T0008 clock-free semantics. It does not implement or verify FIDE
histories, clocks, repetition, intended-claim classification or terminal
adjudication. No converse, holding/determinacy theorem, numerical KRK bound,
exact DTM/DTZ, full FIDE WDL, Syzygy convention parity, new solved material class
or initial-position result follows. A concrete layer must independently prove
all interface fields and the interpretation of its data.

The authoritative source definitions, including the full recurrence:

```lean
import EndgameChess.Rules.ForcingDefinitions

/-! S033 / EC-C022: abstract additive rule layer, not a concrete FIDE history model.
Paper: proofs/EC-C022_RULE_LAYER_PROJECTION.md. Frozen definitions are unchanged. -/
namespace EndgameChess.Rules.HistoryLayer
open EndgameChess.KK

universe u

/-- Actual board steps must project soundly and cover every raw legal reply,
including children which terminate in a draw. Proof fields apply when ongoing. -/
structure Layer (State : Type u) where
  erase : State → Position
  BoardStep : State → State → Prop
  Ongoing : State → Prop
  CanClaim : State → Prop
  step_sound : ∀ {s t}, Ongoing s → BoardStep s t → Legal (erase s) (erase t)
  reply_complete : ∀ {s} {r}, Ongoing s → Legal (erase s) r →
    ∃ t, BoardStep s t ∧ erase t = r
  ongoing_not_dead : ∀ {s}, Ongoing s → ¬ DeadK (erase s)

/-- Exact named-colour board mate is terminal, with no extra claim turn. -/
def Goal {State : Type u} (L : Layer State) (σ : Colour) (s : State) : Prop :=
  MateGoal σ (L.erase s)

/-- Finite budget in board plies. A successful claim is a terminal draw,
not a BoardStep; a defender's available current or intended claim blocks forcing. -/
def RuleMateWithin {State : Type u} (L : Layer State) (σ : Colour) : Nat → State → Prop
  | 0, s => Goal L σ s
  | n + 1, s => Goal L σ s ∨ (L.Ongoing s ∧
      (((L.erase s).turn = σ ∧ ∃ t, L.BoardStep s t ∧ RuleMateWithin L σ n t) ∨
       ((L.erase s).turn = σ.opp ∧ ¬ L.CanClaim s ∧
        (∃ t, L.BoardStep s t) ∧ ∀ t, L.BoardStep s t → RuleMateWithin L σ n t)))

/-- A rule-layer named-colour mate certificate with a uniform finite ply bound. -/
def RuleForceMate {State : Type u} (L : Layer State) (σ : Colour) (s : State) : Prop :=
  ∃ n, RuleMateWithin L σ n s

end EndgameChess.Rules.HistoryLayer
```
